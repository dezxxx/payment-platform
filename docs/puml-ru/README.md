# Диаграммы на русском

Зеркало диаграмм из `docs/*.puml`. Имена файлов совпадают, содержание то же —
переведены заголовки, подписи стрелок и заметки. Идентификаторы (имена классов,
пакетов, полей, HTTP-пути) остаются английскими: это код, а не текст.

**Английские файлы в `docs/` — основные.** При расхождении верной считается
английская версия; правки вносятся в пару, как в `CONTEXT.md` и `CONTEXT.ru.md`.

| Файл | О чём |
|---|---|
| `component.puml` | модули монорепозитория и путь контракта через Nexus |
| `deployment.puml` | локальный стенд: десять контейнеров, порты, кто с кем |
| `layers.puml` | слои individuals-api |
| `registration-sequence.puml` | регистрация, основной сценарий |
| `gateway-flow.puml` | 4 диаграммы: весь путь пользователя, устройство слоя шлюзов, перевод ошибок, где регистрация может сломаться |
| `keycloak-admin-gateway.puml` | 4 диаграммы: шаги регистрации в Keycloak, откат, `/me`, классы Admin-шлюза |
| `error-handling.puml` | 3 диаграммы: путь ошибки, классы пакета `error`, откуда каждое поле ответа |
| `error-two-roads.puml` | две дороги ошибки: до контроллера и после |
| `observability.puml` | метрики, логи, трейсы и один `traceId` |

В файле бывает несколько диаграмм — они разделены парами `@startuml` / `@enduml`.

Смотреть: плагин PlantUML в IntelliJ IDEA (`Ctrl+Shift+A` → *Show PlantUML
preview*) или [plantuml.com/plantuml](https://www.plantuml.com/plantuml).
